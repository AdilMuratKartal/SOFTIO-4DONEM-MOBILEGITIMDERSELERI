# Odaklanma & Pomodoro Zamanlayıcı (Pomodoro View)

Süre bazlı alışkanlıklar ve derin odaklanma oturumları için entegre Pomodoro sayacı.

- **Konum:** `lib/features/views/timer/pomodoro_view.dart`
- **Sorumluluklar:**
  - 3 odaklanma modu: Odaklanma (25 dk), Kısa Mola (5 dk), Uzun Mola (15 dk).
  - Dairesel animasyonlu geri sayım sayacı (`CircularPercentIndicator` / Canvas yay gösterimi).
  - Başlat, Duraklat ve Sıfırla aksiyon kontrolleri.
  - Hangi alışkanlık için odaklanıldığını seçme ve sayaç bittiğinde alışkanlığı otomatik tamamlama.
