# Profil & Başarılar (Profile View)

Kullanıcının seviyesi (XP), kazanılan rozetler ve uygulama ayarlarını yönettiği profil ekranı.

- **Konum:** `lib/features/views/profile/profile_view.dart`
- **Sorumluluklar:**
  - Kullanıcı Level ve XP ilerleme kartı (Örn: Lv. 3 - Seviye İlerlemesi %45).
  - Başarı rozetleri vitrini (Açık ve kilitli rozet kartları, kazanılma tarihleri).
  - En uzun ve mevcut seri (Streak) istatistikleri.
  - Bildirim tercihleri anahtarı.
  - Aydınlık / Karanlık tema modu geçiş butonu (`ThemeMode` switcher).
