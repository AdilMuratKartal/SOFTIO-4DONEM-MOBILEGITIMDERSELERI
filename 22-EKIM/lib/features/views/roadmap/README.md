# Yol Haritası (Roadmap View)

Kullanıcının uzun vadeli kişisel gelişim hedeflerini adım adım (milestones) takip ettiği hedef ağacı ekranı.

- **Konum:** `lib/features/views/roadmap/roadmap_view.dart`
- **Sorumluluklar:**
  - Hazır şablon kütüphanesi (0'dan 5Km Koşuya, 21 Gün Şekersiz, Gitar Başlangıcı, Soğuk Duş Adaptasyonu).
  - Dikey kıvrımlı veya aşamalı düğüm (Node) görselleştirmesi.
  - Kilitli ve tamamlanmış adım durumları.
  - Her aşama tamamlandığında kazanılan XP ve rozet tetikleyicisi.
